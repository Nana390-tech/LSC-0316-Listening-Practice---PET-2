# B1 Preliminary (PET) — Listening Practice Test 2

An interactive, self-marking version of the PET Listening paper, with the four
recordings included.

```
index.html        the whole test — questions, marking, certificate
audio/part1.mp3   Part 1
audio/part2.mp3   Part 2
audio/part3.mp3   Part 3
audio/part4.mp3   Part 4
README.md         this file
```

The page looks for the recordings in an `audio` folder first, and if they are not
there it looks for `part1.mp3` to `part4.mp3` beside `index.html`. Either layout
works — just keep the MP3s in the same repository as the page.

## Putting it on GitHub Pages

1. Create a new **Public** repository, for example `Listening-Practice---PET-2`.
2. Click **uploading an existing file** and drag in `index.html`, `README.md` and
   the four MP3s. They total about 24 MB, so wait for all of them to finish.
3. **Commit changes.**
4. **Settings → Pages →** Source *Deploy from a branch*, branch **main**, folder
   **/ (root)**, then **Save**.
5. After a minute your link appears: `https://<your-username>.github.io/<repo-name>/`
6. Open it, go to Part 1 and press play before sharing it with students.

## What's in the test

- **Part 1** — seven picture questions, drawn as scalable graphics so they stay
  sharp on a phone.
- **Part 2** — Ian's radio talk about difficult neighbours, six multiple-choice
  questions.
- **Part 3** — the Brighton excursion itinerary, six gaps.
- **Part 4** — Simon and Samantha on London, six yes / no statements.

The answer key is built in. A **Mark Part** button scores one part on its own, and
**See my full result** gives a score out of 25, a bar for each part and a
certificate. After marking, every question shows the correct answer with a note on
what in the recording gives it away. The **ع** button shows Arabic instructions.
